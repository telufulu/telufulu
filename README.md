## 🏫 42 Common Core

</div>

**42** is a global, peer-to-peer, project-based software engineering school with no teachers and no tuition fees.
Students learn by building real projects in C, C++, shell and systems programming, reviewing each other's code and progressing through a curriculum that ranges from low-level memory management to networking, graphics and full applications.

Below are the projects I have completed (or am completing) in the **42 Madrid Common Core**.
